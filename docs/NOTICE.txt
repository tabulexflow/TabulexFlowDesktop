C Runtime Libraries (bundled with binary distributions)

Our binary distributions (the PyInstaller frontend binary and the Nuitka
packaged remote tools) bundle the following C runtime libraries. Linking
is dynamic (the .so files sit next to the executable and can be replaced
by the user), except where noted:

  This product includes software developed by the OpenSSL Project for use
  in the OpenSSL Toolkit. (http://www.openssl.org/)

  (eay@cryptsoft.com).
  This product includes software written by Tim Hudson (tjh@cryptsoft.com).
  https://www.openssl.org/source/

libffi.so.8 - MIT License
  https://github.com/libffi/libffi

libexpat.so.1 - MIT License
  https://github.com/libexpat/libexpat

libbz2.so.1.0 - BSD License (bzip2)
  https://sourceware.org/bzip2/

liblzma.so.5 - 0BSD License (XZ Utils)
  https://tukaani.org/xz/

libz.so.1 (zlib) - zlib License
  https://zlib.net/

libxml2.so.2 - MIT License
  https://gitlab.gnome.org/GNOME/libxml2

libxslt.so.1 + libexslt.so.0 - MIT License
  https://gitlab.gnome.org/GNOME/libxslt

libicudata.so.74 + libicuuc.so.74 (ICU) - Unicode License Agreement (Unicode-3.0)
  The full ICU license text is available at:
  https://www.unicode.org/license.txt

libscipy_openblas64_*.so (OpenBLAS) - BSD 3-Clause License
  https://github.com/OpenMathLib/OpenBLAS

libgfortran-*.so + libquadmath-*.so + libgcc_s.so.1 (GCC runtime)
  - GPL-2.0-or-later WITH GCC Runtime Library Exception 3.1
  These libraries are covered by the GCC Runtime Library Exception, which
